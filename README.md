# 🌌 Acerca del proyecto

**Cycle Rental Management System** es un sistema web orientado a la administración y renta de bicicletas, permitiendo gestionar clientes, estaciones y operaciones de alquiler mediante una arquitectura moderna basada en React, Node.js, Express y MySQL.

El sistema fue diseñado para:

- 🚴 Gestionar bicicletas
- 👥 Administrar usuarios
- 📍 Controlar estaciones
- 📅 Gestionar rentas
- 🔍 Consultar disponibilidad
- 📊 Supervisar operaciones
- 🔐 Administrar accesos
- 🌐 Automatizar el sistema de alquiler

# 🚀 Configuración del proyecto

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/isairey/CycleRentalManagementSystem.git
```

---

## 2️⃣ Instalar backend

```bash
cd server
npm install
npm start
```

---

## 3️⃣ Instalar panel administrador

```bash
cd client
npm install
npm start
```

---

## 4️⃣ Instalar aplicación cliente

```bash
cd cust
npm install
npm start
```

---

## 5️⃣ Ejecutar proyecto

### 🛠️ Aplicación administrador

```bash
http://localhost:3000
```

---

### 👤 Aplicación cliente

